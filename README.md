# Binance 市场上涨下跌家数追踪器

这是一个简易网站，会每 10 分钟从 Binance 公共接口抓取全部交易对的 24 小时涨跌幅，并统计上涨、下跌和持平的家数。结果会存储在本地 `data/history.json` 中，并通过折线图展示随时间的变化。

## 快速开始

1. 安装依赖：本项目只使用 Node.js 内置模块，确保本地 Node.js 版本 ≥ 18 即可。
2. 启动服务：

   ```bash
   npm start
   ```

3. 打开浏览器访问 [http://localhost:3000](http://localhost:3000)，即可查看曲线图和实时统计。

## 功能说明

- 服务启动后立即抓取一次数据，并自动对齐到 10 分钟间隔的时间节点持续更新。
- 历史数据保存在 `data/history.json`，默认最多保留约 6 天的记录（864 条 10 分钟数据）。
- 前端页面使用 Chart.js 展示上涨、下跌、持平家数的变化趋势，并支持手动触发立即刷新。
- Binance 接口偶尔可能由于限流失败，界面会在下次自动刷新时恢复。

## 手动刷新

页面底部的“手动刷新”按钮会请求服务器立即抓取一次数据。在遇到 Binance 限流或者网络波动时，可手动尝试刷新。

## 注意事项

- 本项目为示例用途，正式部署时请考虑增加错误告警、持久化存储（如数据库）以及更细致的异常处理。
- 若不希望将 `data/history.json` 的运行数据纳入版本管理，可在 `.gitignore` 中自行忽略。

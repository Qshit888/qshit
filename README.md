# 永续合约小时统计网页

该项目包含一个静态网页，用于展示 U 本位永续合约在每个小时的上涨、下跌与持平家数示例数据。

## 预览网页

有两种推荐方式可以在本地打开网页：

### 方式一：直接打开文件
1. 在文件管理器中找到项目目录下的 `index.html` 文件。
2. 双击或右键选择使用浏览器打开即可。

### 方式二：启动本地静态服务器（推荐）
使用本地服务器可以避免部分浏览器针对本地文件的安全限制。

#### 使用 Python
```bash
python3 -m http.server 8000
```
然后在浏览器访问 <http://localhost:8000/index.html>。

#### 使用 Node.js
如果你安装了 Node.js，可以安装 `serve`：
```bash
npx serve .
```
默认情况下，你可以在终端输出的地址上访问网页（通常是 <http://localhost:3000>）。

## 文件结构
- `index.html`：网页结构。
- `style.css`：样式文件。
- `app.js`：前端逻辑，包含示例数据和图表渲染。

## 后续对接
如果需要接入真实交易所数据，可在 `app.js` 中替换示例数据部分，调用实际的 API 接口后再刷新图表与表格。

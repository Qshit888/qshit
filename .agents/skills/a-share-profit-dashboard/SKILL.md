# A股赚钱效应仪表盘技能

## 输入

流水线模式下读取同一日期目录中的：

- `market_review.md`
- `market_data.json`
- 项目根目录 `AGENTS.md`

禁止改变阶段一市场事实。发现输入冲突时停止并要求阶段一修正。

## PDF固定结构

1. 封面与一句话结论
2. 市场摘要
3. 板块结构总览
4. 最近一天改善/走弱
5. 最新交易日板块排名
6. 最近10—14个交易日热力图
7. 板块趋势线
8. 双板块对比
9. 持续性排名
10. 逐日明细
11. 趋势容量 vs 连板情绪
12. 10cm/20cm/30cm赚钱效应
13. 龙头/中军/弹性前排/后排风险
14. 9:40/9:45/9:50执行计划
15. 仓位策略
16. 数据源、口径与免责声明

## 排版规范

- A4横屏；
- 建议16页以内，内容不足不硬凑；
- 页面有效内容区域约75%—90%；
- 封面主标题24—32pt，一级标题18—22pt，正文11—13pt；
- 表格正文不得低于10.5pt，优先11—12pt；
- 图表坐标与图例不得低于9.5pt；
- 表格放不下时拆页、改卡片/分栏或缩短文字，禁止缩成小字硬塞；
- 避免大面积无意义留白；
- 强弱使用红绿深浅：深红最强，浅红较强，中性待确认，浅绿偏弱，深绿最弱/风险；
- 颜色不能代替文字，必须同时标注分数、阶段或结论；
- 每页标注 `微信：Zhangting8889990`、页码和“仅供学习复盘”；
- 固定免责声明：`本文仅用于个人学习、复盘研究和交易计划推演，不构成任何证券投资建议，也不作为买卖依据。市场有风险，交易需独立判断。`
- 模型评分不得冒充交易所原始数据。

## 图表规范

- 热力图：横轴交易日、纵轴板块；格子和标签可读；
- 趋势线：6—10个代表板块，图例颜色与线条一致，标注拐点、修复、加速、退潮；
- 双板块对比必须回答谁更强、谁更早启动、谁持续性更好、谁中军承接更稳、谁高位透支、次日跟踪谁；
- 持续性排名包含最新强度、平均强度、强势天数、持续性分、最新日变化、阶段和板块效应；
- 逐日明细包含日期、板块、综合强度、持续性、阶段、板块效应、日变化、龙头、中军、弹性前排、后排风险和备注。

## 仓位绑定

- 强主升、趋势与情绪共振：可提高仓位，但不追一致加速；
- 趋势强、连板弱：中等仓位，偏容量中军和分歧承接；
- 指数强、个股弱：低至中仓位，防止权重掩盖亏钱效应；
- 退潮或负反馈扩散：低仓或空仓等待。

## 生成与验收

使用项目可用的Python/PDF工具生成 `outputs/YYYY-MM-DD/dashboard.pdf`。生成后必须渲染所有页面检查，至少抽查封面、热力图、趋势线、最大表格页、执行计划页和仓位页。出现裁切、重叠、乱码、字体过小、图例错色、页脚丢失或留白过大时必须修复后重生成。

## 分页PNG、ZIP和清单

将PDF逐页导出为180 DPI PNG：

- 目录：`outputs/YYYY-MM-DD/dashboard-images/`
- 命名：`page-01.png`、`page-02.png`……
- ZIP：`outputs/YYYY-MM-DD/dashboard-images.zip`
- ZIP根目录直接放图片，不混入源代码或缓存；
- 检查ZIP图片数量等于PDF页数。

生成 `dashboard_manifest.json`：

```json
{
  "date":"YYYY-MM-DD",
  "pdf":"outputs/YYYY-MM-DD/dashboard.pdf",
  "zip":"outputs/YYYY-MM-DD/dashboard-images.zip",
  "wechat_id":"Zhangting8889990",
  "page_count":0,
  "images":[{"page":1,"path":".../page-01.png","purpose":"封面与市场结论"}]
}
```

为每页填写用途，供公众号阶段选择4—8张最有说明力的图片。

## 单独调用

- “分割成图片”：对指定或最新PDF运行分页导出；
- “压缩成ZIP”：生成ZIP并只交付ZIP主链接；
- “优化排版”：修改生成逻辑后重新渲染验证；
- “今天是新的一天，请重新生成”：必须重新联网研究当天数据，不能复用旧日期报告。
